# 审计查询与 CSV 导出

管理员在 **审计记录**（`/audit`）查询配置库中的真实审计。配置人员和只读角色不能查询、导出或下载；此页不提供修改或人工删除记录的功能，也不是运行事件页。默认保留 180 天，部署参数可调长；系统设置中的保留期表单另行实现。

## 查询与范围

- 时间范围为开始时间包含、结束时间不包含。网页按浏览器本地时间输入，发送带时区时间；账号、操作代码和对象为精确匹配，空白条件表示不限。
- 页面每页 50 条，按编号从新到旧。API 每页最多 200 条，使用返回的 `nextCursor` 作为 `before`；不能把游标当作 CSV 的范围。
- 修改筛选框后须点“应用筛选”。未应用修改时列表保留原范围且不允许开始导出；已有导出始终显示它自己的固定条件。
- 详情按原字符串显示，不执行 HTML 或脚本。Token 操作另显示令牌名称；历史账号删除不移除已有审计。

## 生成与下载

1. 核对**整个已应用筛选范围**，勾选确认并生成。`202` 只表示已接收，不代表文件就绪；响应丢失仅重新读取状态，不自动再次提交。
2. 后台在短事务中冻结编号上界，按每页 200 条的独立短连接读取，关闭连接后再写文件。之后新增的审计与本次导出审计不在这份文件内；不只导出当前页，也不按 1,000 条或 64 KiB 静默截断。空范围是只有表头的完整 CSV，读取失败不是空范围。
3. 只有完整文件生成、导出成功审计提交后才开放下载。未就绪、磁盘不足、读取/写入/审计失败均不提供部分文件。
4. 点击“下载完整审计 CSV”走浏览器原生同源下载，不经 JavaScript Blob 全量缓存。下载只允许一次；HTTP 写出完成不等于浏览器已保存，请核对实际下载结果。失败时须重新核对并明确生成。

单网关同时一份审计导出；故障投递 JSON Lines 导出使用不同私有暂存文件。资源绑定创建时的**登录会话或 API Token**，不同会话（即使账号相同）、不同 Token 不能互访，编号本身不是下载凭证。每次访问仍需有效管理员权限，Token 仍只允许 HTTPS；吊销/失效后不能继续发起下载。

有效期为开始请求接收后的 **15 分钟**，包括生成、等待和下载；到期、取消或停机都会触发取消，正在进行的 I/O 结束前不让另一个任务复用槽位。下载租约释放后清理文件。关闭页面不会自动取消后台任务，同一会话刷新可读取当前状态；Host 重启不会续传，上次强杀留下的该功能专属暂存文件在取得数据目录锁后、监听前清理。文件路径不是 API 参数，不遍历删除其他文件；拒绝符号链接/重解析路径。文件 0600、目录 0700（Linux）。

磁盘检查沿用当前网关配置的安全余量，每次实际写入前重新检查；无法确认空间同样拒绝。真实并发用盘仍可能引发 I/O 失败，整份导出会失败。清理失败会明确提示并禁用后续导出，须由主机管理员核对磁盘/权限，处理后重启；不要把此错误当作已清理。

## CSV 格式与安全转换

- UTF-8 BOM，记录分隔符 CRLF；字段使用 CSV 双引号，字段内双引号翻倍，逗号与内嵌换行保留。
- 表头：`id,occurredAt,accountName,tokenName,sourceIp,action,target,result,detail`。
- 时间为带偏移的 ISO 8601；空值是空字段。编号和详情需精确保留时，请在表格软件导入时指定为文本，避免软件自行转换数字或时间。
- **表格公式防护**：字段去掉前导空白后以 `= + - @` 开头，或原文以 Tab/CR/LF 开头时，在字段原文前加一个单引号 `'`。其余文字与内嵌换行不变。这是 CSV 的安全转换，不改写数据库；不承诺所有第三方表格软件采用相同导入策略。
- 文件包含管理员审计详情，应按管理数据妥善保管；原始密码、Token、私钥本来就不得写入审计。

## API 与审计含义

基础路径 `/api/edge-admin/v1`；Cookie 写请求需要 CSRF，Bearer 身份独立认证。

| 方法与路径 | 用途 |
|---|---|
| `GET /audit` | `from/to/account/action/target/before/limit` 筛选分页 |
| `POST /audit/export` | `{"filter":{"action":"auth.login"},"confirmed":true}` 开始完整导出 |
| `GET /audit/export` | 当前身份拥有的导出；没有则 `export:null` |
| `POST /audit/export/{id}/cancel` | 取消自己的任务/文件 |
| `GET /audit/export/{id}/download` | 一次性 `text/csv` 附件 |

`audit.export` 成功表示完整文件生成且该审计已持久化，详情包含范围、编号上界、实际条数和字节数，不是“用户已保存”。`audit.export.download` 表示 HTTP 写出结果。生成失败的审计若也无法存储，沿用原有受限日志降级，但绝不因此开放下载。

导出生成期间只暂缓过期审计删除，不持有跨文件 I/O 的 SQLite reader/事务，也不暂停运行事件清理或新审计写入。碰撞后保留清理每分钟重试，新导出让位于已延后的清理，避免连续导出无限延后保留期。下载前已释放保留租约。
