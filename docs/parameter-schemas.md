# 参数声明与自动表单（T3-10 子项）

本页说明**当前已接线的范围**：六类标量声明/校验、只读元数据 API，以及 Modbus/MQTT 的非秘密连接参数自动表单、已注册纯转换的画布自动表单。配置导入见[导入说明](configuration-transfer.md)。这不是任意第三方适配器已可注册、保存、编译和运行的声明，T3-10 与 T3 整体仍未完成。

## 声明与后端校验

`TenonEdge.Abstractions.Parameters.ParameterSchema` 是不可变、无 I/O 的声明与校验入口。声明包含 ID、用途（Connection/Input/Transform/Output）及参数列表；每个参数可给出字段名、显示名、必填、默认值、范围、说明、分组和对应类型约束。

| 类型 | 普通配置中的表示 | 校验和边界 |
|---|---|---|
| Text | JSON 字符串 | 必须声明最大长度；必填不得仅空白；不自动 trim |
| Number | JSON 数字 | 默认值/最小/最大值在声明中保存为 JSON 原文字符串；精确比较十进制数字，不经 double 舍入；可要求数学整数 |
| Switch | JSON 布尔值 | `false` 是有效的必填值，不把字符串 `"false"` 当布尔值 |
| Choice | JSON 字符串 | 只接受声明中的选项值，显示名不是保存值 |
| Credential | **不属于普通配置** | 仅 Connection 用途允许声明；禁止默认值；普通配置出现此字段，即使是 null 也拒绝 |
| ConnectionReference | 规范十进制字符串 ID | 必须是 1—9007199254740991，按当前连接快照核对存在且协议匹配；无默认引用 |

- 每份声明 1—128 个字段；字段名唯一且符合既有业务 key 规则。文本长度上限 65536；选项及连接类型列表有界。非法声明在构造时拒绝，不带着歧义注册。
- 数字原文最多 128 字符，指数绝对值最多 1000000。比较保留 `9007199254740993`、超精度小数与极小非零数的区别；`1.0` 和 `1e2` 都是数学整数。不使用浏览器 `valueAsNumber`。
- `Validate` 接受 JSON 对象，原文上限 128 KiB、属性数量有界；拒绝未知/重复属性。默认值只用于显式初始化新表单，校验器不会插入默认值、转换类型或修正输入。
- `Validate` 返回字段名与错误代码；未知字段名及提交值不回显。`ThrowIfInvalid` 给现有适配器提供统一拒绝入口；适配器仍负责主机名、ClientId 等协议语义，出站校验仍由原网络模块执行。
- 连接引用校验需要调用方提供**当前事务所读取的连接快照**，不是相信客户端提交的协议；后续实际扩展保存/编译接线必须遵守这一点。本批没有新增使用 ConnectionReference 的持久化业务入口。
- 必填凭证由服务器传入受保护存储中的“已设置字段集合”核对，不接受客户端自报。声明库不负责保存秘密、接收方/积存核对或凭证更新协调，不能替代现有流程。
- 扩展代码本身受信任，不是安全沙箱。不要将秘密伪装为普通文本参数、默认值、显示名或说明；字段名检查不是通用敏感数据检测器。

## 已安装声明 API

```http
GET /api/edge-admin/v1/parameter-schemas/connection.modbus
GET /api/edge-admin/v1/parameter-schemas/connection.mqtt
```

三种已登录角色可读；匿名 401。未知 ID 返回 ProblemDetails 404，代码 `parameters.missing`，不回退为空表单。响应 `Cache-Control: no-store`，只包含声明，不读取凭证或改动草稿。OpenAPI operationId 为 `getParameterSchema`，Web 类型从真实 Development Host 导出。

Host 通过 DI 显式注册声明实例，目录只持有不可变声明，不另建运行时/协议会话，不支持上传 DLL、热加载或网页安装扩展。

## 当前网页行为

`/connections` 的 Modbus/MQTT 标量参数按对应声明生成控件；原业务 key、名称、草稿启用、HTTP 表单、独立凭证/证书、出站规则和连接测试继续使用原流程。

- 六类控件支持声明分组、说明、必填和范围错误定位。数字以文本编辑并精确校验；不依赖浏览器浮点数输入来判断范围。既有连接 Int32 DTO 在提交时将数学整数（如 `1.3e4`）精确规范化为 `13000`，不改变编辑中的原文。
- 新建及显式切换协议时采用声明默认值；重新读取声明或重新读取连接列表不会覆盖尚未保存的编辑。打开已保存连接使用实际草稿值，不重新套默认值。
- 读取声明期间或失败后禁止对应协议保存，保留已经打开的控件与编辑，可显式重新读取；不会静默回退到手写范围，不自动重放保存。未取得 Modbus 声明时不开放默认的“新建连接”。
- 保留内置便利操作：MQTT TLS 切换仅在端口为 1883/8883 时同步默认端口；RTU 静默间隔只在 RTU over TCP 下显示。不引入条件表达式 DSL。
- 自动凭证控件与普通值回调隔离；没有独立凭证处理方时禁用。Modbus/MQTT 当前声明不包含秘密，实际凭证仍在已保存连接下通过原来的身份/接收方/积存核对与确认保存。这批没有新建通用凭证写 API。
- 连接引用下拉只列出匹配协议；原选择已失效时明确提示，不自动选择另一个连接。后端仍必须重新核对，网页不是授权依据。

纯转换现通过独立 `GET /api/edge-admin/v1/transform-modules` 返回 kind/version/显示名及同一参数声明；画布发现、自动表单、草稿/导入/图编译/预览和原运行路径已接通。缺必填/范围错误的转换草稿可暂存但不能应用，未知字段/模块拒绝；边界与证据见[转换模块说明](transform-modules.md)及实施状态 §2.267，不代表输入/输出扩展或 T3 整体已完成。

## 本批不覆盖

- 任意第三方新协议的目录发现、连接草稿持久化、导入导出、计划编译、工厂注册和正式运行接线。
- 输入、转换、输出节点的全部参数声明接线；复杂点表与报文仍由专用编辑器处理。
- 可导入扩展示例与完整扩展开发指南（T5-06），扩展热加载、通用表单设计器或动态页面插件。
- 实物、物理断电、Chrome/Edge/Safari 安装包兼容与远端 CI；不能用单元或 Chromium 软件验证代替。

代码与实际验证证据统一见[实施状态 §2.265](implementation-status.md#2265-t3-10-参数声明与内置连接自动表单2026-10-16)。
