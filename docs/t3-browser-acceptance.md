# T3 最低浏览器与 Excel 外部验收步骤

对应 T3-02/03/11、V-03/10、FE-AT-06、功能需求 §3.7。本文是执行步骤，**不是通过报告**；结果只登记到 [实施状态 §1.1](implementation-status.md#11-t3-有限退出核对矩阵2026-10-19-接续)，不在此维护第二份动态状态表。

## 1. 环境与证据

- 使用实际 Google Chrome 111、Microsoft Edge 111、Safari 16.4、Firefox 128；记录完整版本、操作系统、安装来源和安装包校验值。Chromium 111、Linux WebKit、伪装 User-Agent 不代替相应产品。已有且对应当前源码的报告可复用，不必重跑已通过项。
- Safari 需要实际受支持的 Apple 环境。Excel 验收需要真正从 Excel 复制单元格，记录 Excel 完整版本；脚本构造 paste 事件、TSV 文本框或其他表格软件均不算这条证据。
- 旧浏览器只访问隔离测试网的自有 Host，不访问生产站点、不录入真实凭证。使用独立浏览器 profile、临时数据目录和测试账号；Safari 使用专用测试系统/用户。仅在该测试 profile 或专用用户钥匙串登记证书，不更改日常浏览器或日常系统的信任。
- 每份结果记录代码提交、前端构建、测试时间、HTTP/HTTPS URL、实际版本、每步结果、截图和错误日志。性能写实测耗时与内存指标的口径（JS 堆或进程 RSS），没有测量就写未测，不虚构阈值。
- 截图、HAR 和日志不能带密码、Cookie、CSRF 或 Token；不要公开原始认证请求。仅记录步骤所需的非秘密信息。

## 2. 独立 Host

按 [Web 工程说明](../web/README.md) 固定安装、构建后，在仓库根执行。将 IP 改为本机隔离测试网卡，确认两个端口未被占用；不要复用已有产品实例的数据目录。

```sh
IP=192.168.0.88
DATA=$(mktemp -d)
printf '本次临时测试数据：%s\n' "$DATA"
ASPNETCORE_ENVIRONMENT=Production dotnet src/TenonEdge.Host/bin/Release/net10.0/TenonEdge.Host.dll \
  --webroot="$PWD/web/dist" \
  --TenonEdge:DataDirectory="$DATA" \
  --TenonEdge:Http:Address="$IP" --TenonEdge:Http:Port=18490 \
  --TenonEdge:Https:Address="$IP" --TenonEdge:Https:Port=18491
```

用前台终端 Ctrl+C 停止自己启动的 Host；确认退出并保存脱敏证据后，再按打印的精确路径清理这一个临时目录。不要用通配符停止其他 Host 或清理其他目录。

HTTP 使用 `http://<IP>:18490`，不能改成 localhost。HTTPS 使用 `https://<IP>:18491`：先核对控制台输出的证书 SHA-256 指纹，再在隔离测试环境按浏览器支持的方式登记该信任锚；不得使用忽略证书错误开关。无法建立经过核对的信任时，记 HTTPS 未验证，不能把证书警告页当作成功。HTTP 和 HTTPS 分别登录，Cookie 不互通。

## 3. 每个最低浏览器的双协议冒烟

HTTP 和 HTTPS 各执行一次，分别留结果：

1. 新数据目录的首个会话完成真实首次设置；之后退出、重新登录。已有账号时直接登录，不要求重开设置窗口。记录 HTTP 明文提示。换协议后必须重新登录，不能继承另一协议会话。
2. 打开 `/prototypes/points` 深链并刷新，仍显示点表。开发者工具只读核对 `window.isSecureContext`：网卡 HTTP 为 false，已信任 HTTPS 为 true；操作中无安全上下文 API 报错。
3. 在表格中通过系统剪贴板粘贴，验证错误定位、修改和覆盖；真实 Excel 来源的独立验收按下节执行。V-10 另在全新原型页粘贴 1,000 行，再追加 9,000 个不同 key，合计 10,000 行；滚动到末行仍可编辑。记录页面显示的粘贴/校验时间及同阶段浏览器内存，不把采样 RSS 写成峰值。
4. 打开 `/prototypes/canvas`，从面板拖入一个输入、两个映射和一个输出，实际从端口拖线；输入不能被连入、输出不能再连下游，两个映射之间形成环的连线被拒绝并提示。
5. 选择、移动、复制粘贴、删除节点；缩放、平移、适应画布和小地图可用。重新打开原型页并添加一个映射节点，在“节点名称”中依次输入“映射0”至“映射54”，每次点击“修改名称”；点击“撤销”50次后名称为“映射4”，再点击“重做”50次后为“映射54”。另检查键盘快捷键（macOS 用对应的 ⌘）：文本框内撤销不删除画布节点。
6. 查看自有格式：定义与布局分开，不持久化 React Flow 私有状态。记录控制台错误及实际截图。

原型页只验证交互，**不保存、不采集**。真实保存、应用、外部发送和关闭浏览器/Host 重启由实施状态中对应无 JSON 端到端证据覆盖，不能用原型替代。自动化入口见 Web 工程说明；其中普通 Playwright Host 命令只开测试 HTTP，不能仅改 URL 为 https 就声称执行了 HTTPS 验收。

## 4. Excel 100 行真实剪贴板

在 Excel 新工作表按以下 **9 列顺序**准备数据，不含表头。先准备第 1 行，再选中 A1:I100 使用“向下填充”（不是自动递增序列），保持 C 列恒为 3；公式按所在行计算：

| 列 | 内容 | Excel 第 1 行示例 |
|---|---|---|
| A | key | `="excel_"&(ROW()-1)` |
| B | 名称 | `="点位"&ROW()` |
| C | 功能码 | `3` |
| D | 协议偏移 | `=ROW()-1` |
| E | 类型 | 文本 `uint16` |
| F | 位号 | 空 |
| G | 字节序 | 空（uint16 不需要） |
| H | 单位 | 文本 `kPa` |
| I | 启用 | 文本 `true`（可先设为文本格式） |

将 A51 改为 `bad/key`，D76 改为 `65536`。在 Excel 选中 **A1:I100** 并复制：

1. 网卡 HTTP 下打开空点表，地址写法选“协议偏移（从 0 开始）”，粘贴方式选“追加新行”。聚焦“可编辑点表”区域（不是单个输入框），按 Ctrl+V/⌘V。
2. 预期恰为 100 行、2 行错误；第 51 行 key 和第 76 行地址分别标错并可定位。合法邻行保持原文，空 F/G 列不能导致单位、启用错位；记录截图。
3. 在页面改回 `excel_50`、`75`，预期 0 行错误。选择两行批量修改单位，只改变所选行。
4. 先取消其他行选择，只选择一行，改为“覆盖所选行（数量须一致）”。在另一工作表准备一条九列记录，key 为尚未使用的 `excel_replacement`，复制后粘贴，预期总行数仍为 100，其余行不变。再保持只选一行而复制两行粘贴，预期提示数量不一致、原 100 行不变。
5. 在隔离 Host 的设备页创建测试 Modbus 连接/设备/采集组（例如 UnitId=1、周期=5秒），使用仍含两个错误的原 Excel 表格再次粘贴；错误未修正时不能保存，修正后点击“保存来源草稿”、刷新重新打开仍为 100 点。连接地址可用文档示例 `192.0.2.1:502`，**不要点击连接测试、读取或应用**；此步骤不需要真实设备，也不证明接入成功。保存后可能出现出站检查/白名单提示，此验收不需要放行示例地址。
6. HTTPS 下用空原型页和新的设备来源重复剪贴板步骤，保留独立结果。用于 1,000/10,000 行原型测量时，使用新工作表的原始公式（不要扩展带 `bad/key` 和 `65536` 的错误样例），向下填充至第 10,000 行。先复制 A1:I1000，再复制 A1001:I10000 追加；key 为 `excel_0`—`excel_9999`，地址为 0—9999，均不重复。

报告注明复制源是实际 Excel、复制范围、是否包含表头、浏览器与协议。没有这个复制源，只能登记普通粘贴路径测试，不能核销功能 §3.7 的 Excel 项；也不要求为每种浏览器重新执行同一 Excel 业务闭环来人为扩大矩阵，最低浏览器冒烟与 Excel 来源证据分别登记。
