# 配置 JSON 交换（T3-10，实施中）

本页描述配置交换，不是运行版本恢复或备份恢复。统一验证证据见 [实施状态](implementation-status.md)。

## 当前交付：导出已保存草稿

配置人员或管理员在 **系统信息与设置 → 配置草稿导出** 下载 `tenonedge-configuration.json`。只读角色没有下载入口，服务端也拒绝访问。

- 导出的是一次短事务读取的**当前已保存完整草稿**，包括停用、未引用与未完成对象；不包含页面尚未保存的编辑，不是当前有效运行版本。
- 不应用配置、不推进草稿版本、不操作运行时或队列。
- 最多 16 MiB。引用不存在、内容格式异常、凭证元数据冲突或文件超限时整体拒绝，不生成部分文件。
- 下载请求使用共享预览并发预算，租约保持到响应写出结束或中断。客户端不自动重试；离开页面或退出会话后，不下载迟到文件。
- 配置内容仍可能含现场地址、非秘密业务数据与模拟样本，下载后须妥善保管。不能通过字段名称检查来保证任意业务文本永远没有用户手填的秘密。

### 文件内容

格式版本为 `1`。根对象只有 `formatVersion`、`connections`、`devices`、`inputs`、`routes`：

| 对象 | 标识与引用 |
|---|---|
| 连接 | `connectionKey` |
| 设备 | `deviceKey`；通过 `connectionKey` 引用连接 |
| 来源 | `deviceKey` + 设备内 `inputKey`；点位/字段的业务 `key` 原样保留 |
| 路线 | `routeKey`；输入节点用 `sourceKeys: ["deviceKey/inputKey"]`，输出节点用 `connectionKey` |
| 路线节点/布局 | 路线内局部 `id`、连线、布局保留，它们不是数据库资源编号 |

非秘密协议参数、映射和组装规则保留；JSON 数字由后端写出原精度，浏览器直接下载 UTF-8 字节，不经 JavaScript 数字解析再序列化。

已登记凭证的连接只附带 `credential.status: "requiresInput"` 与不可用于认证的账户比较摘要 `accountIdentity`。不输出用户名、账户 marker、凭证版本、密文或秘密；没有读取/解密秘密。摘要只用于后续导入的保守账户比较，不能作为凭证恢复方式。API Key 的头/查询参数名及秘密版本不属于账户身份；不相同或无法确认的摘要只能保守要求重填。

不导出受信任证书、内部资源编号、NodeId/GatewayId、平台映射、用户、API 令牌、系统设置、队列、审计和配置版本历史。导出不能替代备份。

### API

`GET /api/edge-admin/v1/configuration/export`

- Configurator / Administrator；Cookie 会话或已有管理认证授权，Viewer 为 403，未登录为 401。
- 可选 `expectedVersion` 固定草稿版本，过期返回 409；省略则导出同一事务捕获的当前草稿。
- 成功返回 `application/json` 附件与 `Cache-Control: no-store`。
- 引用缺失/元数据冲突为 409，格式或版本参数无效为 400，超限为 413，共享预算耗尽为 429。失败返回 ProblemDetails，不返回附件。

## 导入：上传预检 → 核对 → 确认写入草稿

配置人员或管理员在同一系统页的 **配置草稿导入** 选择文件，默认使用合并模式；替换模式会删除文件以外的全部草稿对象。

1. 页面读取当前草稿版本，以原始 UTF-8 字节上传 JSON；不先在浏览器解析和重新编码，避免大整数精度损失。
2. 预检返回完整新增、修改、删除及连接凭证清单。展开对象可查看前后原文；列表每页 25 项，不截断变更。预检不写草稿、不联网测试或应用配置。
3. 核对模式、所有变更及凭证重填要求，勾选声明后确认。只有本会话或原 API 令牌可确认；同一账号的另一次登录不能接管。
4. 确认只原子写入草稿、索引、编辑日志和审计。随后还须在配置变更页独立预检并应用；需重填的凭证必须先补齐。运行指针、当前秘密、待发队列不在导入事务中修改。

### 冲突与失败

- 合并按业务 key 新增/更新，未导入对象保留；路线整体替换。替换使草稿与文件一致。新对象分配本机内部编号，不能借用文件里的数据库编号。
- 同 `connectionKey` 的协议类型不可变。合并/替换发现 HTTP 改 MQTT 等情况时，整次预检失败，返回 `$.connections[n].kind` / `import.connectionKindImmutable`，须改用新 key。
- 文件格式、模块、标识、引用或合并后大小有任何错误时均不写入草稿。不截断文件、不部分导入。错误列表最多 128 项，超过时明确标记 `import.issuesTruncated`，不表示其余内容通过。
- 当前凭证只有在接收方和不可认证账户摘要均一致时保留；缺失、无法确认或接收方改变时，持久标记为需重新填写。导入不会替换当前秘密；既有凭证待补标记也不能通过去掉文件提示绕过。
- 全网关只保留一份待确认候选，15 分钟按单调时间过期，Host 重启即失效。其他会话不读取或覆盖它；同会话再次进入上传预检会先作废旧候选，文件校验失败也不会恢复旧资格。认证/CSRF/格式头/共享预算等入口拒绝发生在读取文件之前，不视为开始新的预检。
- 确认在锁内一次消费；事务内再次检查操作者有效身份/角色、草稿版本、当前凭证元数据及保留身份。任何冲突或审计失败均整体回滚，不恢复确认资格。
- 取消等待、失败或回复丢失不等于撤回数据库提交。页面立即移除旧确认按钮，不自动重试；先重新读取草稿核对，再决定是否重新上传。离页取消等待，不自动重放；可以显式读取仍属于本会话的待确认候选。

### 导入 API

以下接口均要求 Configurator / Administrator；Cookie 写请求须 CSRF，令牌仍只允许 HTTPS。返回 `Cache-Control: no-store`。

| 方法与路径（前缀 `/api/edge-admin/v1`） | 内容 |
|---|---|
| `POST /configuration/import/prepare?expectedVersion=…&mode=merge` | 原始 `application/json` 请求体，UTF-8，最多 16 MiB；`mode` 可为 `merge`（默认）或 `replace`。返回候选 id、版本、模式、完整差异、凭证清单和显示用到期时间 |
| `GET /configuration/import` | 返回 `{review: …}`，没有本会话候选时为 `{review: null}`；不返回其他会话的内容 |
| `DELETE /configuration/import/{id}` | 取消本会话的候选，不修改草稿 |
| `POST /configuration/import/confirm` | 只接受 `{id, confirmed: true}`，成功返回新草稿 `version`；额外字段拒绝 |

上传、读取、取消和确认均使用原共享预览预算；上传在取得共享预算及导入独占槽位后才读取请求流。单次上传/预检限时 30 秒，读取最多上限加 1 字节用于超限探测。完整差异响应写出结束/取消前保留共享租约。

格式/字段错误为 400 ValidationProblem（JSON 路径 → 稳定错误码），超限为 413，内容类型不符为 415，上传超时为 408，版本/凭证冲突或导入槽忙为 409，候选不存在/过期/非本会话为 404，共享预算耗尽为 429。确认后遇到失败不得以同一 id 自动重放。

## 验证边界与剩余项

内部解析、标识重映射、凭证比较、待补标记和原子导入的先行证据见实施状态 §2.243—§2.245；这些历史阶段当时没有 HTTP 导入或网页。当前 API/网页的实际验证见实施状态 §2.253，不将内部服务单测当作浏览器验收。

六类扩展参数声明、同源校验和自动表单仍在 T3-10 内继续实施；当前配置交换或点表 CSV 不能替代这些要求。导出不等于备份，导入不等于运行计划、配置应用或软件升级。
