# 新连接类型：版本化草稿与共享运行

T3-10 子场景。当前已接通**编译期连接声明 → 认证发现/非秘密草稿/业务key导入导出 → 冻结连接 → 已注册输入模块 → 原共享连接/出站检查/监督者 → 原队列及HTTP输出**。独立凭证的后端与真实TCP轮换子场景已接入；网页自动表单与任意新输出传输仍未完成，不能把这一软件子场景当作T3-10或T3交付完成。

## 声明和准入

`ConnectionModuleDefinition`是适配器的辅助元数据，通过Host的原DI显式注册；不是第四类可执行扩展，不安装、扫描或热加载程序集。它声明kind、正整数version、显示名及Connection用途的`ParameterSchema`。类型遵守原运行单元kind的小写点分段规则；不能覆盖http/mqtt/modbus/tenon，同kind/version不能重复注册，不自动采用最新版本。

`ConnectionModuleCatalog`只持有不可变声明。`Freeze`先按声明校验，再生成`ModuleConnectionSnapshot`；参数保留精确JSON数字，拒绝未知、重复、范围错误的属性，默认值不隐式填入。有显式接收方绑定的连接允许保存缺凭证的非秘密草稿，实际运行准备/重建时由独立凭证解析器核对必填材料；没有绑定声明的必填凭证、尚未接入的嵌套连接引用仍拒绝准入。不能凭种子文件自报“已设置”。普通参数中出现Credential字段（包括null）仍被拒绝，不把秘密存进运行快照。

适配器使用的`ReadModuleConfiguration`和`ModuleConfigurationIdentity`随`ModuleConnectionSnapshot`放在Abstractions中，只依赖BCL；不要求Adapters反向引用Runtime来读取快照或计算共享身份。声明目录与宿主准入继续属于Runtime/Host。

连接实例仍由`ISharedConnections`持有，工厂只构造本地对象；协议语义由适配器在纯构建阶段校验。联网必须借用共享租约并经`IOutboundConnector`执行实际IP出站检查；超时、取消、串行执行、最后释放及观察机制沿用原契约。受信任代码不是沙箱，不允许把秘密伪装为普通文本参数。

## 冻结格式与历史

下例是内部运行快照片段，**不是配置导入文件**，也不是产品自带的新业务协议：

```json
{
  "connectionId": 10,
  "kind": "testwire",
  "configuration": {
    "connectionModule": {
      "version": 1,
      "parameters": { "host": "127.0.0.1", "port": 19001 }
    }
  }
}
```

输入模块仍按原参数名引用连接ID字符串，并通过`InputUnitContext.Connections`获取冻结快照。声明注册本身不放行示例回环地址；实际网络访问仍需要部署/网页出站授权。

- 新种子、冻结、人工重试及运行构建使用当前宿主目录验证连接类型/版本/参数；另一目录已解析的计划或历史结构读取不能绕过本机准入。
- 历史读取只核对冻结结构、上限和快照哈希，不执行模块或要求连接声明仍已安装。参数最多128项、128KiB，必须为标量对象；不改写旧格式或内容哈希。
- 类型声明缺失时，启动仍加载原有效快照；原准备机制仅将引用它的单元标记为构建失败，其他输入和已冻结队列发送继续。恢复正确声明后按原快照启动。
- 共享会话配置身份包含kind、version和全部冻结参数，不把变更后的参数误借给旧会话；**这个身份不是输出接收方指纹**，不能拿它替代凭证账户、目标变更或迁移保护。
- 同一连接ID的协议/参数必须一致，与内置协议交叉冲突也拒绝。新连接计入原500个全局上限及管理员收紧后的计划准入限制。
- 统一连接查询纳入这些冻结引用、使用者和共享通信观测，不执行协议或回显参数。未实现的通用目标描述明确显示“目标由适配器解析”，不从任意标量猜地址；旧种子仍没有可编辑草稿。

## 草稿、导入与编译

认证后的三种角色均可通过`GET /api/edge-admin/v1/connection-modules`读取固定版本的声明，响应`no-store`；发现不执行适配器。默认产品没有测试协议声明。创建/更新继续使用原`/connections`管理API，只允许配置人员及管理员，并沿用Cookie/CSRF、全局草稿版本、唯一业务key与原子审计。

请求仍指定`kind`，扩展使用`module`，并在`module`对象里明确真实类型、版本与非秘密标量。例如测试侧声明注册后：

```json
{
  "expectedVersion": "0",
  "key": "wire",
  "name": "测试连接",
  "kind": "module",
  "module": {
    "kind": "testwire",
    "version": 1,
    "parameters": { "host": "127.0.0.1", "port": 19001 }
  }
}
```

这不是产品默认可用协议，也不授予示例地址出站权限。规则如下：

- 保存前按本机精确kind/version声明校验；未知版本、必填缺失、范围错误、重复/未知参数、嵌套对象或秘密字段拒绝，默认值不自动补入。准确保留数字原文。
- 同key的真实协议类型不可变：`module/testwire`不能改成`module/otherwire`或HTTP；明确选择已安装的另一声明版本可以保存，不自动升级。内置协议数据结构不改，旧草稿/快照不会多出`module: null`而改变比较内容。
- 历史/草稿读取与导出只做结构检查，声明卸载后仍可查看、导出或删除无引用草稿。新的保存、导入和启用配置编译必须经当前目录准入。不会在读取时执行模块或悄悄采用最新版本。
- 来源引用仍使用原显式参数名→连接ID，冻结时带出真实kind/version/参数，再经输入目录校验；应用与预检使用同一目录。共享运行计划与完整草稿检查点均保留该版本。扩展输入连接不会被误当HTTP队列发送者。
- 导出保留连接业务key和非秘密版本参数，来源引用换成key；合并/替换导入按本机key匹配或分配新ID，两种模式均禁止同key换真实类型、拒绝缺声明/版本。只有声明了凭证及显式接收方绑定的模块才接受非秘密凭证提示；按接收方与账户摘要核对，跨Host导入必须补填材料，普通文件永不接受秘密。
- 删除仍经原事务复核设备/来源/路线、保留有效/上一/待定版本及三分区投递；核对或查询不是授权绕过。移除草稿使用者不解除有效快照的引用保护。
- 网页提供独立扩展连接编辑器，按已安装的精确版本声明生成非秘密标量表单；不把扩展参数交给Modbus/MQTT表单。卸载声明后仍可查看原参数，禁止保存或自动切换版本。连接自身的嵌套连接引用尚未接入，遇到该声明明确只读。

## 网页操作

进入“连接 → 新建扩展连接”，明确选择已安装的类型与版本，填写非秘密参数并保存草稿。重新打开该连接后，在独立凭证面板填写公开账户及秘密，核对本次草稿的绑定字段和原新身份摘要，再明确确认。换址保留仅管理员可用，必须先核对新绑定；没有接收方声明时不提供通用秘密写入能力。查询失败或回复丢失时先重新读取，不重复点击保存。

默认产品没有authwire等测试声明；本批真实TCP浏览器验证由测试程序集登记，设备/来源/路线及应用仍为API夹具，不是完整无JSON配置或新输出传输验收。说明与测试范围见实施状态§2.287。

## 独立受保护凭证

`ConnectionModuleDefinition`可显式声明`RecipientParameters`：从同一份参数声明中选择不重复、必填、非秘密标量。`RecipientIdentity`将kind、version及这些字段规范化后计算摘要；超时等未选中的运行参数不改变绑定。不能猜测任意host/url字段，也不能把全部共享配置身份当成接收方。声明和协议的接收方语义由受信任适配器负责；它不是自动地址识别或完整输出指纹。

```http
GET /api/edge-admin/v1/connections/{id}/module-credential
PUT /api/edge-admin/v1/connections/{id}/module-credential
POST /api/edge-admin/v1/connections/{id}/module-credential/review
DELETE /api/edge-admin/v1/connections/{id}/module-credential?expectedDraftVersion=…&expectedVersion=…
```

- 一个连接一份材料，可包含多个声明的Credential字段。秘密只写入独立`module_credential`表，Data Protection按用途及连接ID隔离，不进入草稿、快照、导出或审计。仅配置人员/管理员可写，沿用原认证/CSRF；GET供三角色读取非秘密状态与身份，`no-store`，没有记录返回404。
- PUT核对全局`expectedDraftVersion`和凭证`expectedVersion`。新材料必须提供可见`account`及`secrets`字典，字段必须来自Credential声明且满足必填；每值最多65536字符、编码后总材料128KiB、请求体256KiB。普通配置出现秘密字段仍拒绝。普通轮换不推进草稿版本；补齐导入待补凭证标记属于草稿修改，会返回新版本。
- 接收方只按当前同版本草稿计算，不信任客户端地址。换址默认作废，重新填写后可用；只有管理员能以`retainExisting: true`显式保留原可解密材料。保存非秘密草稿本身不改变正在运行的冻结目标；重绑后旧冻结输入不能解析新绑定材料。
- 有待发/失败数据且可见账户未变时，必须显式给出`accountChanged`，没有默认值。true生成新账户标记，false保留；材料版本不等于账户身份。写入复用原发布身份屏障，最多等待5秒，在事务内再次核对版本，审计失败则整次回滚；不修改既有队列正文或编号。**这不是新输出传输的身份冻结、实际隔离或迁移验收**，这些仍须后续接入原输出路径。
- 被保留运行版本引用或存在待发/失败/隔离记录时不能清除。允许删除未引用草稿时，同时清除独立材料并记原审计。COMMIT换接收方的作废、回滚的当前材料核对、管理员恢复审批的凭证版本核对均沿用原事务边界，不恢复历史秘密。
- `IModuleCredentialResolver`按冻结连接解析当前材料，使用短命数据库客户端；适配器每次认证/请求取得当前版本，不缓存秘密到计划。可选凭证无记录可匿名；有记录但损坏、密钥不可用或接收方不符时不能退成匿名。长期认证会话的轮换重连由协议适配器按该契约实现，本批真实TCP测试使用逐请求认证，不宣称覆盖所有协议会话。
- 网页凭证面板独立于普通配置：先保存/重载草稿，输入公开账户与声明的秘密字段，再核对绑定参数、原新公开身份和动态积存。核对不发送或解密秘密；保存仍走原事务与身份屏障，不把核对当作授权租约。需账户声明时不预选，明确确认后一次保存。管理员保留也先核对新绑定，清除须确认。
- 秘密仅在组件内存与密码输入中，不放进Zustand、Query变量或浏览器持久存储。取消、失败、冲突或丢回复会同时清空内存和输入框；结果未知须先显式重新读取，不能自动重放。普通草稿保存丢回复也须重新读取服务器上的实际草稿，不能用缓存恢复旧版本。后台查询不覆盖本地非秘密编辑。
- 没有为模块添加TLS、忽略证书错误或第二套出站/连接管理。缺绑定的声明不会凭空具备凭证能力。

## 实际验证与尚缺部分

测试侧实现一个有界的8字节响应协议，两个输入共享一个真实TCP会话，收到超过2^53的整数后经原SQLite队列发送HTTP；未放行的本机端口被原出站规则拒绝。三次正常Host生命周期验证共享释放、卸载连接声明、单元降级、原HTTP待发正文/编号补发和恢复。它不是产品协议、实物/物理断电、TLS或新类型凭证验证。

新增草稿链路验证覆盖角色/CSRF、精确数值、乐观并发、类型不可变、审计失败回滚、卸载后的读取/导出，以及两种导入模式的本机ID重映射。真实TCP链路从认证连接API、原设备/来源/路线存储和跨Host导入开始，显式应用后双输入共享会话；卸载连接声明正常重启，原HTTP冻结正文/编号仍可补发，未应用草稿不被覆盖。它含API/内部服务测试夹具，不是浏览器无JSON全流程或强杀/物理断电。原网页兼容用例继续验证：未知声明可查看，但不能保存或打开错误的内置协议编辑器。

独立凭证网页核对/保存与连接标量自动表单已接线；浏览器实测范围见实施状态§2.287。六类表单的完整组合及新输出传输的完整账户/积存保护仍须继续。输出模块仍委托原HTTP/MQTT工厂，没有放宽为直接发送新传输，也未绕过其接收方指纹/迁移保护。可发布扩展示例与完整开发指南仍属于T5-06。

实际命令、环境和验证证据见实施状态§2.284（冻结运行基础）、§2.285（版本化草稿与原链路）、§2.286（独立凭证后端）及§2.287（连接网页与凭证核对）。
