# 点表 CSV

适用范围：所选 **Modbus 设备的已保存草稿**。不会读设备、启动采集或应用配置。来源（采集组）须先创建；CSV 不创建来源，也不修改来源周期或设备启用状态。

## 页面操作

在“数据来源与点位”页先保存或关闭来源编辑，再使用“设备点表 CSV”：

1. 下载模板，或导出当前设备的全部点位。模板使用第一个已保存来源；没有来源时使用占位 `input_1`，导入前须先创建对应采集组或修改 inputKey。
2. 选择文件及实际编码（UTF-8 或 GBK），选择模式：
   - **增量**：只新增，设备内已有的点位 key 跳过。仍验证文件全部行，包括将被跳过的行。
   - **覆盖**：同 key 更新、新 key 新增；文件中没有的点位保留。同 key 指定其他已有 inputKey 时，将点位移至该组。
3. 导入成功会显示新增、更新和跳过数量。有任何错误则整个批次不写；错误中的 `csv[行号]` 是文件的物理起始行号（含表头，带换行的引号字段可能占多行）。修正后重新导入。
4. 草稿版本冲突时文件保留；核对其他人的修改，刷新后再显式重试。不要把网络超时当成导入失败并盲目重试，应先刷新核对草稿。

按总设计 §10.3，导出、模板和导入均仅限配置人员与管理员；只读角色不能操作。服务端使用全局草稿版本和一次事务，审计失败也会回滚。即使所有行都跳过，导入操作仍推进一次版本并记录一次审计。保存不等于应用。

## 格式

逗号分隔；允许双引号包裹字段，内部双引号写为 `""`；允许引号内换行，接受 CRLF 或 LF。导出统一 **UTF-8 BOM + CRLF**。导入必须明确选择 UTF-8 或 GBK，不猜测编码，不以替换字符吞掉解码错误。

表头列可重新排序，但不得缺列、重复或增加未知列：

```csv
inputKey,key,name,functionCode,address,addressNotation,type,bit,byteOrder,unit,enabled
fast,temperature,温度,3,40001,manual,uint16,,,℃,true
fast,ready,就绪,1,00001,manual,bool,,,,false
```

| 列 | 含义 |
|---|---|
| inputKey | 当前设备内已保存采集组的 key，不是显示名称 |
| key | 设备内唯一字段 key；1—64 个 ASCII 字母、数字、`.`、`_`、`-`，首字符为字母或数字；文件中不得重复 |
| name / unit | 可空，最多 64 字符；字符串，不参与数值换算 |
| functionCode | `1`、`2`、`3`、`4`，分别是只读线圈、离散输入、保持寄存器、输入寄存器 |
| addressNotation | 必填 `offset`（零基偏移）或 `manual`（完整手册编号）；每行明确声明，不根据数字猜测 |
| address | offset 为 0—65535；manual 为 5 或 6 位完整编号，例如 `40001`、`00001`，功能码必须与前缀一致。Excel 中应将此列及 inputKey/key 列设为文本，避免前导零丢失、日期转换或长数字舍入 |
| type | `bool`、`bit`、`int16`、`uint16`、`int32`、`uint32`、`float32`、`int64`、`uint64`、`float64` |
| bit | 仅 `bit` 填 0—15；其他类型留空 |
| byteOrder | 32/64 位必须填 `ABCD`、`CDAB`、`BADC`、`DCBA` 之一；16 位、bit、bool 留空。64 位排列含义与点表编辑器/适配器一致 |
| enabled | 必填小写 `true` 或 `false`；副本/导入不会自动启用所属设备 |

导入后地址统一保存为零基偏移。导出按设备的地址写法生成 address 和 addressNotation；导出的文件可以直接再次导入。跨越地址 65535 的多寄存器点位、非法位号或不匹配的类型/字节序都会报错，停用点也须满足定义约束。

### 电子表格文本保护

导出时，name/unit 的公式起始字符（`=`、`+`、`-`、`@`）、前导空白/控制字符/BOM 会添加一个前导单引号；原有前导单引号加倍。导入会反向还原这些标记。例如原名称 `=1+1` 导出为 `'=1+1`，原名称 `'literal` 导出为 `''literal`。手工编辑文件时，要保留字面单引号也应按此规则转义。保护不改变保存的名称或单位。不要使用电子表格程序去执行不可信的 CSV 内容。

## 边界

- 文件最多 **5 MiB 或 10000 条数据记录**，先达到者生效；单个单元格最多 4096 字符。
- 每个采集组导入后的点位总数不得超过 10000。跨组移动按最终结果检查。
- 设备点位超过单文件上限时导出会明确拒绝，不截断并伪装成完整导出。
- 模板和导出不含连接、凭证、设备 ID、运行值或运行状态；审计只记录设备 ID、模式、计数和版本，不记录文件正文。
- API 使用 JSON 中的 base64 原始文件字节上传，保留 GBK 字节；请求体上限 8 MiB，解码后的 CSV 仍严格限制为 5 MiB。

本功能不等于配置备份/跨网关导入，也不提供协议连通性证明。测试范围与未验证事项见 [实施状态](implementation-status.md)。
