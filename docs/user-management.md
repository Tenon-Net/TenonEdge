# 本地账号与管理员重置

## 首次设置与登录

在服务启动后的设置窗口内访问网页，填写管理员账号（默认 `admin`，可修改）、密码和确认密码；网关名称可选。两次密码不一致不会发送设置请求。密码强度仍由网关校验，不是仅靠网页校验。

HTTP 会明文传输密码、凭证与会话，仅用于可信管理网络。使用 HTTPS 时先核对网关证书。HTTP 与 HTTPS 的登录互不通用。

管理员在 `/users` 新建用户或重置用户密码时设置的是**临时密码**。用户登录后必须先修改，之前不能进入管理功能。用户自行改密后，当前会话重新签发，其他旧会话失效；管理员改角色、停用、重置密码或强制下线后，该用户的旧会话在下一次请求时失效，已打开的页面回到登录。

用户操作须核对并确认；版本冲突或回复丢失时先“重新读取用户”，不要自动重放。失败登录也可能改变账号的锁定计数和编辑版本。最后一个启用管理员不能删除、停用或降级；管理员不能删除自己。

## 忘记管理员密码

1. 在主机侧停止网关。运行中的服务持有数据目录锁，重置命令会拒绝执行。
2. 使用同一版本的程序、同一绝对数据目录执行 `reset-admin --account <账号>`；不指定账号时为 `admin`。例如开发构建可执行：

   ```sh
   dotnet src/TenonEdge.Host/bin/Release/net10.0/TenonEdge.Host.dll reset-admin \
     --account admin --TenonEdge:DataDirectory=/绝对路径/网关数据
   ```

3. 启动服务，在重新开放的 30 分钟窗口内访问网页。重置表单锁定为命令指定的账号，填写新密码与确认密码，不会创建第二个账号或修改网关名称。命令不接收或输出密码。
4. 其他未重置的启用账号可选择“使用其他已有账号登录”；重置窗口关闭也不阻止正常账号登录。“返回管理员重置”只在窗口仍开放时提供设置表单。

重置会撤销指定账号的旧会话，不会重置其他管理员。主机命令和完成设置均留有审计。重新设置完成后，重启不再开放设置入口。

**安全提示：** 重置窗口允许访问管理端口的人为指定账号设置新密码。请在隔离、可信的管理网络操作，完成后核对总览中的设置来源 IP 和审计记录。不要把数据目录、会话或密码放进公开日志。

验证范围和失败记录统一见[实施状态 §2.241](implementation-status.md)。本说明不表示 T3 整体或所有最低浏览器已完成验收；证书替换和 HTTPS-only 仍按 T5-01。
